# 🚀 Live Deployment Guide for DD Marketing

Is `live` folder me aapki website ke sabhi production-ready files hain. Aap ise kisi bhi hosting par 1-minute me live kar sakte hain:

---

## 📁 Live Folder Contents:
1. `index.html` — Production Landing Page with complete SEO & Real Estate schema.
2. `dist/` — Compiled TypeScript JavaScript files (`main.js`, `calculator.js`, `form.js`, `theme.js`, `navigation.js`, `types.js`).
3. `sitemap.xml` — Google Search Console ready XML Sitemap.
4. `robots.txt` — Search engine indexing rules.
5. `.htaccess` — Apache/cPanel/Hostinger speed & caching configuration.
6. `vercel.json` & `_redirects` — Vercel & Netlify routing config.

---

## 🌐 Option 1: Hostinger / cPanel / Shared Hosting par Live karna:
1. Apne **Hostinger / cPanel** ke **File Manager** me jayein.
2. `public_html` folder open karein.
3. Is `live` folder ke andar ki **sari files (`index.html`, `dist/`, `sitemap.xml`, `robots.txt`, `.htaccess`)** ko zip karke `public_html` me upload karein aur Extract kar dein.
4. Aapki website instantly live ho jayegi!

---

## ⚡ Option 2: Vercel / Netlify par Free Live karna:
1. [Vercel.com](https://vercel.com) ya [Netlify.com](https://netlify.com) par free account banayein.
2. Direct is `live` folder ko drag & drop karein ya GitHub repository connect karein.
3. Instant 10 seconds me global CDN par HTTPS ke sath live ho jayegi!
